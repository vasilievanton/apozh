# Наоборот

Страница для записи голоса по частям. Части склеиваются в одну дорожку, и она переворачивается задом наперёд. Сверху задания: перевёрнутые WAV, их можно слушать целиком и по частям. Задания переключаются вкладками, у каждого свои записи.

## Запуск на GitHub Pages

1. Создай репозиторий и загрузи в его корень `index.html` и этот `README.md`.
2. Положи туда же файлы заданий: `zadanie.wav` (Задание 1), `zadanie2.wav` (Задание 2) и `zadanie3.wav` (Задание 3). Имена пишутся строчными буквами: GitHub различает регистр, и `Zadanie.WAV` страница не найдёт.
3. Открой Settings → Pages. В Source выбери Deploy from a branch, ветку `main` и папку `/ (root)`, нажми Save.
4. Через пару минут страница откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

## Заменить или добавить задание

Чтобы заменить задание, залей новый файл поверх старого с тем же именем.

Список заданий лежит в начале скрипта в `index.html`, в `TASKS`. Чтобы добавить ещё одно, допиши строку вроде `{ url: 'zadanie4.wav', title: 'Задание 4' }` и положи файл в корень.

## Нарезка задания

Сначала задание режется по 2 секунды. Количество частей и их длина меняются кнопками − и +. Каждую границу можно перетащить на волне, тогда у частей будет разная длина.

## Проверить у себя

В папке с файлами запусти `python -m http.server` и открой `http://localhost:8000`. Двойной клик по `index.html` не подойдёт: так браузер не даёт странице прочитать файлы заданий.
