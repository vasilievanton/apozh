# Наоборот

Страница для записи голоса по частям. Части склеиваются в одну дорожку, и она переворачивается задом наперёд. Сверху задание: перевёрнутый WAV, его можно слушать целиком и по частям.

## Запуск на GitHub Pages

1. Создай репозиторий и загрузи в его корень `index.html` и этот `README.md`.
2. Положи туда же файл задания под именем `zadanie.wav`. Имя пишется строчными буквами: GitHub различает регистр, и `Zadanie.WAV` страница не найдёт.
3. Открой Settings → Pages. В Source выбери Deploy from a branch, ветку `main` и папку `/ (root)`, нажми Save.
4. Через пару минут страница откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

## Заменить задание

Залей новый `zadanie.wav` поверх старого. Если нужно другое имя файла, поменяй `TASK_URL` в самом начале скрипта в `index.html`.

## Проверить у себя

В папке с файлами запусти `python -m http.server` и открой `http://localhost:8000`. Двойной клик по `index.html` не подойдёт: так браузер не даёт странице прочитать `zadanie.wav`.
